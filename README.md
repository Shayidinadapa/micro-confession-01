A two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint" bounty: a `To:` line naming who the unsent message was meant for, and the unsent line itself, exactly as it was typed. The confession is specific and honest, and the reason it stayed in drafts — too afraid to say sorry, and no longer sure the sorry would even be true — is felt in the words, not stated. The `To:` line and the message need each other: the betrayal only stings because it was done to a best friend of nearly a lifetime.

`main.ts` (Node 22, standard library only) writes the confession to `/output/entry.txt` — 177 characters, no trailing newline, the same bytes on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
